# AI 활용 기록

이 문서는 게임 제작 과정에서 사용한 AI 도구, 프롬프트, 채택 결과 및 사람의 수정 판단을 기록합니다.

## 2026-08-06 — 콘셉트 및 개발 환경

- 사용 도구: OpenAI Codex
- 목적: 사전과제 조건 분석, 게임 콘셉트 구체화, 웹 기술 스택 선정 및 초기 프로젝트 구성
- 주요 지시 사항:
  - 브라우저에서 즉시 실행 가능한 게임으로 제작
  - 플레이어와 적 모두 한 발에 사망
  - 조준 중 시간 정지 및 도탄 예상선 표시
  - 발사 후 비무장 상태로 총알 직접 회수
  - GitHub Pages에 배포 가능한 정적 빌드 구성
- AI 제안 중 채택:
  - Vite + TypeScript + Phaser 구성
  - 총알이 플레이어에게도 피해를 주는 규칙
  - 반사벽·흡수벽·유리벽으로 장애물 역할 구분
- 사람의 최종 결정:
  - 모바일 앱 대신 웹 게임으로 제출
  - 런타임 생성형 AI나 외부 API는 사용하지 않음
  - AI는 제작·코딩·검토 과정에 활용하고 기록을 공개
  - 최신 시험판 조합 대신 Phaser 3.90.0, Vite 7.3.5, TypeScript 5.9.3으로 버전을 고정
  - Windows 개발 서버는 외부에 노출하지 않고 `127.0.0.1`에만 바인딩

> 이후 AI를 사용할 때마다 날짜, 도구, 프롬프트 요약, 생성 결과, 채택 여부와 수정 이유를 추가합니다.

## 2026-08-06 — 플레이 완성도 및 구조 개선

- 사용 도구: OpenAI Codex
- 목적: 프로토타입을 5개 구역으로 확장하고 충돌 안정성, 연출, 유지보수 구조 보완
- 주요 지시 사항:
  - 플레이 편의 기능을 제외한 기술·콘텐츠·연출·제출 준비 항목 수정
  - 조준 오버레이와 입력 이탈 문제 수정
  - 빠른 탄환이 대상을 통과하지 않도록 연속 충돌 판정 적용
  - 스테이지 5개와 보스 1종 구현
  - 외부 에셋 없이 효과음과 파티클 생성
- AI 제안 중 채택:
  - 선분-원 교차 기반 탄환 충돌과 회귀 테스트
  - 데이터 기반 스테이지 정의
  - Web Audio API 기반 합성 효과음
  - 게임 상수, 타입, 스테이지, 충돌, 사운드 모듈 분리
- 사람의 최종 결정:
  - 기존의 한 발 즉사 규칙은 일반 적에게 유지
  - 최종 보스만 3중 보호막을 사용해 캠페인 종착점으로 차별화
  - 모바일 조작, 설정, 기록 저장 등 플레이 편의 기능은 이번 변경 범위에서 제외

## 2026-08-07 — 최신 픽셀 화면과 로컬 개선 작업 병합

- 사용 도구: OpenAI Codex
- 목적: 원격 저장소의 코드 생성 픽셀 화면에 로컬의 5개 스테이지, 연속 충돌, 효과음, 모듈 구조 적용
- 적용 내용:
  - 16×16 플레이어·일반 적·탄환 텍스처와 픽셀 던전 팔레트 유지
  - 36×40 크기의 전용 보스 텍스처를 새로 구성하고 일반 적보다 약 3~4배 크게 렌더링
  - 보스 중앙 자수정 코어, 보호막 결정, 보라색 그림자와 3단계 보호막 HUD 추가
  - 선분 기반 탄환 충돌, 파티클, 화면 흔들림, Web Audio 효과음과 5개 스테이지 병합
  - 개발 환경에서 `?stage=5` 주소로 보스 스테이지를 직접 검증할 수 있도록 구성
- 검증:
  - 충돌 단위 테스트 4개 통과
  - TypeScript 및 Vite 프로덕션 빌드 통과
  - 로컬 브라우저에서 1스테이지와 보스 스테이지 렌더링 및 콘솔 오류 확인

## 2026-08-08 — 회수 압박과 움직임 품질 개선

- 사용 도구: OpenAI Codex
- 목적: 팀원이 제안한 긴장감 강화 아이디어를 기존 핵심 루프에 통합하고 조작감을 개선
- 주요 지시 사항:
  - 탄환 미보유 중 적을 강화하고 눈빛을 밝게 표시
  - 탄환과 멀어질수록 화면 가장자리 회수 방향과 박동 효과 강화
  - 조준·발사·미보유·회수 상태에 맞춰 절차적 사운드 변화
  - 예고 후 돌진, 적 또는 탄환을 가까스로 피했을 때 짧은 슬로모션 적용
  - 후반 적 수 감소와 보스 보호막 파괴에 맞춰 압박 단계 강화
  - 위험한 회수와 도탄 플레이에 점수 보상 제공
- 적용 내용:
  - 입력 가속·감속과 적 조향 보간을 추가해 급격한 방향 전환을 완화
  - 탄환 비행 중 플레이어와 적을 모두 고정하고, 회수 단계에서만 양쪽 움직임을 재개하는 상태 규칙을 분리해 테스트
  - 미보유 20%, 후반 8%의 적 속도 배율을 독립 계산하고 단위 테스트로 고정
  - 회수 단계에서 경로 갱신 주기와 돌진 재사용 시간을 줄여 적의 공격성을 강화
  - 적 눈빛·위험 테두리·후반 배경색, 화면 가장자리 회수 화살표와 거리 표시 구현
  - 적 접촉 근접 회피까지 슬로모션 범위를 확대하고 반복 발동 방지 시간 적용
  - 회수 거리·반사·연속 처치·근접 회피를 조합한 SAFE/BOLD/RECKLESS 보너스 도입
- 사람의 최종 결정:
  - 회수 제한시간은 넣지 않고 시청각 압박과 적 강화만 적용해 탐색 선택권 유지
  - 단순히 오래 버티는 행동을 보상하지 않도록, 회수 보너스는 탄환 정지 순간의 거리로 확정
  - 보스는 보호막 파괴 시 속도 증가·돌진 해금·추적자 증원을 사용하고 장애물 붕괴는 제외

## 2026-08-09 — 캐릭터 및 조준 화면 아트 디렉션 개선

- 사용 도구: OpenAI Codex
- 목적: 기존 화면의 낡은 프로토타입 인상을 줄이고 캐릭터성과 탄도 정보 전달력을 강화
- 주요 지시 사항:
  - 직선 위주의 궤적 표시를 덜 촌스럽고 절제된 방식으로 변경
  - 플레이어와 적이 단순 사각형으로 보이지 않도록 고유 실루엣 부여
  - 픽셀 스타일을 유지하되 오래된 게임처럼 보이는 반복 격자와 회색 장애물 개선
- 적용 내용:
  - 흰 머리, 호박색 스카프, 청록색 회수 건틀릿을 가진 24×28 플레이어 캐릭터와 보행 프레임 제작
  - 뿔·마스크·발광 눈을 가진 추적자 디자인과 보행 프레임 제작
  - 밝은 실선 궤적을 감쇠되는 점선과 소형 반사 마커로 교체
  - 플레이어에게 돌아오는 예상 구간만 붉은색과 `RETURN FIRE` 경고로 표시
  - 64px 산업 패널, 청록색 모서리 조명, 서비스 라이트와 입체 장애물로 전장 재구성
  - 인물 중심 비대칭 타이틀 화면과 현대적인 산세리프 HUD 적용
- 사람의 최종 결정:
  - 외부 이미지 에셋 없이 모든 픽셀 텍스처를 Phaser Graphics 코드로 생성
  - 정확한 반사 정보는 유지하되 화면을 지배하지 않도록 바운스가 늘수록 궤적 투명도를 낮춤

## 2026-08-09 — 회수 전투 압축 및 조준 취소 추가

- 사용 도구: OpenAI Codex
- 목적: 전장 크기에 비해 느슨했던 초반 회수 구간을 압축하고, 발사 직전의 선택을 되돌릴 수 있게 개선
- 주요 지시 사항:
  - 맵을 좁혀 적과 플레이어의 접촉 빈도 상승
  - 적의 추적·돌진 압박 강화
  - 조준 상태에서 발사를 취소할 수 있는 입력 추가
- 적용 내용:
  - 기존 1172×574 작전 구역을 960×500으로 압축하고, 스테이지의 플레이어·적·장애물 좌표를 동일한 비율로 재배치
  - 기본 적 속도 12% 상승, 경로 갱신 주기 단축, 돌진 준비·재사용 시간 단축, 돌진 유효 거리 확장
  - 일반 적도 예고 후 돌진할 수 있도록 확장하고, 탄환 미보유 중에는 더 빠른 경로 갱신과 돌진을 적용
  - 조준 중 우클릭 또는 `Esc`로 조준을 취소하고, 멈춘 적의 행동 시계를 정상적으로 재개하도록 기존 취소 로직 연결
- 사람의 최종 결정:
  - 조준 취소에는 탄약·점수·시간 페널티를 부여하지 않아, 실패한 각도를 즉시 버리는 판단 자체를 전술 선택으로 유지

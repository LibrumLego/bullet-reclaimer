# 탄환 회수자 — 45초 플레이 영상 촬영 구성

실제 브라우저 플레이 화면만 녹화한다. 편집으로 게임 규칙을 바꾸거나 AI 합성 화면을 넣지 않는다.

| 구간 | 화면 | 전달할 내용 |
| --- | --- | --- |
| 0–4초 | 타이틀에서 START 클릭 | 제목과 픽셀 던전 분위기 |
| 4–10초 | 1스테이지: 마우스를 누르고 도탄 예상선 표시 | 조준 중 시간이 멈춘다는 핵심 규칙 |
| 10–16초 | 버튼을 놓아 한 발 발사, 적 처치 | 단 한 발과 반사 공격의 쾌감 |
| 16–24초 | 멈춘 탄환 쪽으로 이동, 적 사이를 피해 회수 | 발사 뒤 무방비 상태가 되는 긴장감 |
| 24–33초 | 2·3스테이지: 장애물 사이 2회 이상 반사로 연속 처치 | 장애물이 많은 전투 설계 |
| 33–41초 | 실패 장면 또는 자신의 탄환 회피 장면 뒤 R 재시작 | 플레이어도 한 발에 죽는 규칙 |
| 41–45초 | 보스 코어와 3중 보호막 HUD, 게임 로고 | 5구역·보스까지 있는 완성된 구성 |

## 촬영 전 설정

- 브라우저 줌 100%, 다른 탭·알림·주소창 개인정보가 보이지 않도록 한다.
- 게임 캔버스를 한 번 클릭해 키보드 포커스를 둔 뒤 `WASD`로 이동한다.
- 1080p, 60fps 또는 30fps로 녹화하고, 실제 마우스 조준·발사·회수가 보이도록 한다.
- 완성본은 30–60초, YouTube `일부 공개` 또는 `공개`로 업로드한다.
- 업로드 URL을 게임 소개 PDF의 `플레이 영상` 행에 반영한 뒤 최종 제출한다.

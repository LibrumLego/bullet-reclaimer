# 탄환 회수자 · Bullet Reclaimer

> **한 발이면 충분하다. 다시 주울 수만 있다면.**

시간을 멈춰 단 한 발의 도탄 궤적을 설계하고, 발사 후 비무장 상태로 총알을 회수하는 2D 탑다운 액션 게임입니다.  
NAN 2026 Game × AI Hackathon 사전과제 출품작으로 제작 중입니다.

## 게임 한눈에 보기

| 항목 | 내용 |
| --- | --- |
| 장르 | 시간 정지 도탄 액션 · 전술 퍼즐 |
| 플랫폼 | 웹 브라우저 (GitHub Pages) |
| 플레이 시간 | 스테이지당 1~3분 |
| 조작 | `WASD` 이동 · 마우스 조준/발사 · `R` 재시작 |
| 핵심 위험 | 플레이어와 적 모두 총알 한 발에 즉사 |

## 핵심 루프

1. 마우스 버튼을 누르면 시간이 멈추고 도탄 예상선이 나타납니다.
2. 각도를 설계해 단 한 발을 발사합니다.
3. 발사와 동시에 시간이 다시 흐릅니다.
4. 총알이 멈춘 위치까지 적을 피해 이동해 회수합니다.
5. 모든 적을 제거하면 다음 구역으로 이동합니다.

총알은 적뿐 아니라 플레이어도 즉사시킵니다. 멋진 다중 도탄을 노릴수록 총알을 되찾는 경로가 더 위험해집니다.

## 디자인 원칙

- **한 발, 한 판단**: 탄약을 쌓아 두지 않아 모든 발사가 전략적 선택이 됩니다.
- **읽히는 위험**: 조준 중에는 정지하지만, 발사 뒤에는 실시간으로 위험을 감당해야 합니다.
- **회수의 긴장감**: 처치 자체보다 총알이 어디에 멈추는지가 다음 행동을 바꿉니다.
- **짧고 선명한 스테이지**: 한 방의 실패와 즉시 재도전이 반복되는 구조를 목표로 합니다.

## 기술 스택

- [Phaser 3](https://phaser.io/) — 2D 게임 프레임워크
- [TypeScript](https://www.typescriptlang.org/) — 게임 로직
- [Vite](https://vite.dev/) — 개발 서버 및 정적 빌드
- GitHub Actions + GitHub Pages — 자동 배포

## 로컬 실행

```powershell
npm.cmd install
npm.cmd run dev
```

프로덕션 빌드:

```powershell
npm.cmd run build
npm.cmd run preview
```

로컬 개발 서버는 Windows 환경에서의 안전을 위해 `127.0.0.1`에서만 실행됩니다.

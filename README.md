# 탄환 회수자 · Bullet Reclaimer

> 시간을 멈춰 단 한 발의 반사 궤적을 설계하고, 무방비 상태로 탄환을 회수하는 탑다운 액션 게임.

[플레이하기](https://librumlego.github.io/bullet-reclaimer/) · [NAN 2026 Game × AI Hackathon 제출 프로젝트](https://nan2026.nhn.com/)

## 핵심 한 줄

**총알은 단 한 발. 쏜 뒤에는 직접 주워 와야 한다.**

탄환은 적과 플레이어 모두를 한 번에 쓰러뜨린다. 조준하는 동안에는 시간이 멈추지만, 발사하는 순간부터 플레이어와 적이 다시 움직인다. 빗나간 탄환을 회수하러 가는 길 자체가 다음 전투의 리스크가 된다.

## 현재 플레이 버전

- `WASD` 또는 방향키: 이동
- 마우스 버튼을 누르고 있는 동안: 시간 정지 및 반사 경로 조준
- 마우스 버튼을 놓기: 탄환 발사
- `R`: 즉시 재시작
- 탄환: 벽과 장애물에 최대 5회 반사
- 적, 플레이어, 자신의 탄환: 모두 한 번 맞으면 즉사

첫 번째 전투 구역은 반사 각도와 회수 경로를 함께 판단하도록 구성되어 있습니다. 적을 모두 제거하면 구역 클리어, 적에게 닿거나 돌아온 탄환에 맞으면 즉시 실패합니다.

## 게임 루프

1. 적이 움직이는 상황에서 안전한 위치를 잡는다.
2. 마우스를 누르면 시간이 멈추고 반사 예상 궤적이 표시된다.
3. 발사하면 무장 해제 상태가 되고 시간이 다시 흐른다.
4. 탄환이 멈춘 곳까지 적을 피해 접근해 회수한다.
5. 모든 적을 제거할 때까지 반복한다.

## 기술 구성

- [Phaser 3](https://phaser.io/): 2D 렌더링과 입력 처리
- [TypeScript](https://www.typescriptlang.org/): 게임 상태와 반사 로직
- [Vite](https://vite.dev/): 개발 및 정적 웹 빌드
- GitHub Actions + GitHub Pages: 자동 배포

현재 그래픽은 코드로 그린 도형만 사용하며, 외부 이미지·사운드 에셋은 사용하지 않았습니다.

## 로컬 실행

```powershell
npm.cmd install
npm.cmd run dev
```

프로덕션 빌드:

```powershell
npm.cmd run build
npm.cmd run preview
```

Windows 환경에서 개발 서버는 `127.0.0.1`에만 바인딩됩니다.
